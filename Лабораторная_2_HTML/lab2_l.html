1. Гипертекст (Hypertext)

Гипертекст — термин, введённый Тедом Нельсоном в 1965 году для обозначения текста, ветвящегося или выполняющего действия по запросу. В современном понимании гипертекст представляет собой форму организации текстового материала, при которой смысловые единицы (фрагменты текста, статьи, разделы) представлены не в линейной последовательности, а в виде сетевой иерархической структуры со множеством взаимосвязанных переходов.

Основным инструментом реализации гипертекстовых переходов выступают гиперссылки (гиперсвязи). Активация гиперссылки пользователем приводит к мгновенному отображению ассоциированного фрагмента документа или загрузке нового информационного ресурса. На принципах гипертекста построена Всемирная паутина (WWW), где языком разметки выступает HTML (HyperText Markup Language).

2. URL (Единый указатель ресурса)

URL (Uniform Resource Locator) — унифицированный указатель ресурса, служащий стандартизированным способом записи адреса любого информационного объекта в глобальной сети Интернет. Концепция URL была разработана Тимом Бернерсом-Ли в 1990 году в рамках создания базовой архитектуры Всемирной паутины.

Стандартная структура URL включает в себя: схему протокола доступа (например, http, https, ftp), имя хоста или доменное имя сервера, номер сетевого порта (при отличии от стандартного), путь к файлу в файловой системе сервера, строку параметров запроса и имя якорного фрагмента (хэш). Благодаря адресации URL веб-клиенты получают возможность однозначно идентифицировать и запрашивать документы, мультимедийные файлы и программные интерфейсы.

3. Протокол HTTP (HyperText Transfer Protocol)

HTTP (HyperText Transfer Protocol) — прикладной протокол передачи данных, изначально ориентированный на обмен гипертекстовыми документами в формате HTML, а в настоящее время применяемый для передачи произвольных типов бинарных и структурированных данных. Протокол функционирует поверх транспортного протокола TCP и реализует классическую клиент-серверную архитектуру взаимодействия.

Каждый сеанс взаимодействия по протоколу HTTP состоит из запроса клиента (содержащего метод, URI, заголовки и тело сообщения) и ответа сервера (включающего код состояния, заголовки и передаваемый контент). Базовыми методами протокола являются GET, POST, PUT, DELETE, HEAD. Современный веб опирается на защищенную версию HTTP — протокол HTTPS, обеспечивающий шифрование сессий с помощью криптографических протоколов TLS.
